How options work

Name an option and list its choices with commas, like Colour: Black, White and Size: S, M, L. Put the one that changes how the product looks first (usually Colour), then link each photo to a colour below. You set the stock for each choice, and the total above adds itself up.

Start from an example:
Option 1 the one that changes the look, like Colour
Option 2 optional, like Size

Leave a price empty to use the product price. Removed choices are switched off, so old orders keep their details.
